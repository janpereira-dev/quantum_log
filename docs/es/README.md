M4 está `IN_PROGRESS`. La captura de Copilot VS Code sigue siendo experimental hasta que evidencia real de extremo a extremo registre uso originado en Copilot en SQLite. La calidad de captura siempre es explícita; QUANTUM_LOG no inventa conteos de tokens.
