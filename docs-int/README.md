# Internal Delivery Documentation

This area records delivery history, acceptance evidence, release procedures, and planning artifacts. It is not public product documentation.

Public product docs live in [`docs/`](../docs/README.md). Use them for installation, operation, architecture, privacy, and contribution guidance. Use this area to review whether delivered work has evidence to support its claims.

## Internal Routes

- [Milestone status](milestones/README.md): delivery-state index and verification rule.
- [Verification evidence](verification/): acceptance matrices and capture evidence.
- [Release procedures](releases/): distribution and release-hand-off material.
- [Specifications](specs/): historical technical designs.
- [Plans](plans/): implementation plans and delivery history.

## Evidence Rule

Delivery evidence supports claims about a particular milestone or release. It does not replace public product documentation, and public documentation must not claim a capability beyond its supporting evidence.
